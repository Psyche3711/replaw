# 已废止法规库 - 反洗钱反恐怖融资

## 📖 项目简介

这是一个专业的互联网网页应用，用于展示和查询**反洗钱和反恐怖融资领域已废止的法规**。

数据来源：《已废止法规：反洗钱反恐怖融资（截至20250331）》

## ✨ 核心功能

### 1. 📊 统计仪表板
- 显示已废止法规总数（**83条**）
- 按法规类型分类统计：
  - 法律/司法解释
  - 行政法规
  - 部门规章/规范性文件
  - 团体/行业规定

### 2. 📈 可视化图表
- **甜甜圈图**：展示法规类型分布比例
- **柱状图**：显示各年份废止法规数量趋势

### 3. 🔍 智能筛选系统
支持多维度筛选：
- **按年份筛选**：选择2003-2026年之间的任意年份
- **按类型筛选**：选择特定的法规分类
- **按关键词搜索**：支持搜索"反洗钱"、"客户尽职调查"等关键词

### 4. 📋 规范化列表
- 卡片式设计，清晰展示每条法规信息
- 包含：法规名称、分类、年份、废止日期、废止依据
- 分页浏览，每页10条记录

## 🛠️ 技术栈

- **前端**：HTML5 + CSS3 + JavaScript (ES6+)
- **图表库**：Chart.js
- **响应式设计**：Mobile-first
- **数据**：静态JSON格式

## 🚀 快速开始

### 本地运行
直接在浏览器中打开 `index.html` 文件即可。

### 部署到GitHub Pages

1. **创建GitHub账号**（如果没有的话）
   - 访问 https://github.com
   - 注册免费账号

2. **创建新仓库**
   - 点击 "+" → "New repository"
   - 仓库名：`replaw`（或其他名称）
   - 选择 "Public"（公开）
   - 点击 "Create repository"

3. **上传文件**
   - 进入仓库页面
   - 点击 "Add file" → "Upload files"
   - 上传 `index.html` 和 `README.md`
   - 点击 "Commit changes"

4. **启用GitHub Pages**
   - 进入 Settings → Pages
   - Source 选择 "Deploy from a branch"
   - Branch 选择 "main" → "/ (root)"
   - 保存

5. **访问网站**
   - 等待几分钟后，访问：
   - `https://your-username.github.io/replaw/`
